# দাওয়াহ প্ল্যাটফর্ম ওয়েবসাইট

সম্পূর্ণ static সাইট — কোনো ব্যাকএন্ড, ডাটাবেস বা Supabase লাগে না। VS Code দিয়ে সরাসরি এডিট করা যায়।

## ফোল্ডার স্ট্রাকচার

```
salafi-dawah/
├── index.html          ← পেইজের কাঠামো (সাধারণত এডিট করার দরকার নেই)
├── style.css            ← ডিজাইন/রং
├── content.js           ← *** এই ফাইলটাই মূলত এডিট করবেন ***
├── main.js              ← রেন্ডার লজিক (এডিট করার দরকার নেই)
└── assets/              ← PDF ফাইল ও ছবি রাখার জায়গা
```

**জরুরি:** সব ফাইল একই ফোল্ডারে ফ্ল্যাটভাবে থাকা উচিত (কোনো `css/` বা `js/` সাবফোল্ডার নেই) — `index.html`-এ লিংকগুলো ঠিক এভাবেই বসানো আছে। ফাইল সরালে বা সাবফোল্ডারে রাখলে সাইট styling/script ছাড়াই লোড হবে।

## কীভাবে কনটেন্ট আপডেট করবেন

`content.js` ফাইলটা VS Code দিয়ে খুলুন:

1. **সাইটের নাম/ট্যাগলাইন** — `site` অবজেক্টে বদলান
2. **ইউটিউব/টেলিগ্রাম প্রধান লিংক** — `youtubeChannelUrl`, `telegramUrl` এ নিজের লিংক বসান (হেডার ও হিরো সেকশনের বাটনে ব্যবহার হয়)
3. **নতুন ভিডিও যোগ** — `videos` অ্যারেতে একটা নতুন `{ videoId, title, description }` লাইন যোগ করুন। `videoId` হলো YouTube URL এর `?v=` এর পরের অংশ
4. **নতুন PDF যোগ** — PDF ফাইল `assets/` ফোল্ডারে রাখুন, তারপর `pdfs` অ্যারেতে `{ title, url, size }` যোগ করুন

কোনো পরিবর্তনের পর ব্রাউজারে রিফ্রেশ দিলেই বদল দেখা যাবে।

## লোকালি চালানো (VS Code)

VS Code এ **Live Server** extension ইনস্টল করুন → `index.html` এ right-click → "Open with Live Server"।

(শুধু ফাইল ডাবল-ক্লিক করে খুললেও চলবে, তবে ফেইসবুক embed ঠিকমতো কাজ নাও করতে পারে — Live Server বা যেকোনো লোকাল সার্ভার দিয়ে চালানোই ভালো)

## ফ্রি হোস্টিং

- **GitHub Pages**: রিপোতে পুশ করে Settings → Pages থেকে চালু করুন — সম্পূর্ণ ফ্রি
- **Netlify** / **Vercel**: ফোল্ডারটা ড্র্যাগ-ড্রপ করলেই ফ্রি ডোমেইনসহ লাইভ হয়ে যাবে

## কমিউনিটি লিংক (Facebook/Telegram/YouTube ইত্যাদি) যোগ করা

"কমিউনিটিতে যুক্ত হোন" সেকশনে যত ইচ্ছা কার্ড দেখাতে পারেন — `content.js`-এর `communityLinks` অ্যারেতে নিচের প্যাটার্নে একটা এন্ট্রি যোগ করলেই নতুন কার্ড দেখাবে, HTML/CSS ছোঁয়ার দরকার নেই:

```js
{
  title: "নতুন পেইজ/গ্রুপের নাম",
  description: "এক লাইনের সংক্ষিপ্ত বিবরণ।",
  url: "https://...",
  buttonText: "ভিজিট করুন"
}
```
